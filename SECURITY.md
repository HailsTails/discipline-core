# Security policy

## Supported versions

Only the newest release of Hone is supported. If you are on an older release, update to the newest one before reporting.

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a vulnerability.

Report it privately through GitHub's private vulnerability reporting on this repository: open the Security tab and choose "Report a vulnerability". Only the maintainer can see the report.

## What to expect

Hone is maintained by one person in their own time, and no response time is promised.
