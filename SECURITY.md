# Security policy

## Supported versions

Only the newest release of Hone receives security fixes. If you are on an older release, update to the newest one before reporting, in case the problem is already fixed.

## Reporting a vulnerability

Please report it privately, not in a public issue, pull request or discussion.

Use GitHub's private vulnerability reporting: open the repository's Security tab and choose "Report a vulnerability". Only the maintainers can see the report.

Include what you found, how to reproduce it, which Hone release you ran, and your Node.js version and operating system. A minimal repository that shows the problem helps most.

## What to expect

You will get a reply within a week. If the report is a vulnerability, the maintainers will work on a fix with you in the private report, release it, and credit you in the advisory if you want to be named. If it is not a vulnerability, they will say why. Please keep the details private until a fix is released.
